# Technology & Digital Innovation Hub - SMK Bandar Machang

A modern, fully functional educational technology website for SMK Bandar Machang's Technology & Digital Innovation Hub.

## Overview

This website serves as the school's central digital innovation ecosystem for teachers, students, and the educational community. It provides:

- **Artificial Intelligence** exploration and learning
- **Digital Learning** resources and competencies
- **Coding & Programming** education
- **STEM & Robotics** development
- **IoT Projects** and smart solutions
- **Digital Creativity** showcase

## Features

### ✨ Modern Design
- Futuristic dark theme with vibrant accent colors
- Smooth animations and transitions
- Responsive design for all devices
- Interactive particle effects

### 🎯 Key Sections
1. **Hero Section** - Dynamic introduction with animated statistics
2. **About** - Vision, mission, and values
3. **Programs** - Six core program areas with detailed information
4. **Project Showcase** - Filterable gallery of student and teacher projects
5. **Resources** - Learning materials, tutorials, and tools
6. **Contact** - Interactive contact form and information

### 🔧 Technical Features
- Smooth scrolling navigation
- Mobile-responsive hamburger menu
- Project filtering system
- Form validation
- Scroll reveal animations
- Parallax effects
- Performance optimized

## How to Use

### Opening the Website

Simply open `index.html` in any modern web browser:

1. Double-click `index.html`
2. Or right-click and select "Open with" → Choose your browser

**No installation or build process required!**

### File Structure

```
websiteTekVokSMKBM/
├── index.html          # Main HTML file
├── css/
│   └── styles.css      # All styling and animations
├── js/
│   └── main.js         # Interactive functionality
├── assets/             # Images and media (add your own)
├── pages/              # Additional pages (if needed)
└── README.md           # This file
```

## Customization

### Changing Colors
Edit the CSS variables in `css/styles.css`:

```css
:root {
    --primary-color: #00d4ff;
    --secondary-color: #7b2cbf;
    --accent-color: #ff6b6b;
    /* ... more variables */
}
```

### Adding Projects
Add new project cards in `index.html` under the Project Showcase section:

```html
<div class="project-card" data-category="ai">
    <div class="project-image">
        <!-- Add your image here -->
    </div>
    <div class="project-content">
        <span class="project-category">AI</span>
        <h3>Your Project Title</h3>
        <p>Project description...</p>
    </div>
</div>
```

### Modifying Content
All text content is in `index.html`. Simply edit the HTML to change:
- Taglines and titles
- Program descriptions
- Contact information
- Footer content
